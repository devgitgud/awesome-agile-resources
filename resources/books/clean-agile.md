# Clean Agile

## Description

Clean Agile by Robert C. Martin revisits Agile values and principles from their original intent.

## Why we recommend it

It helps teams focus on foundational Agile thinking instead of ceremony-driven implementation.

## Pros

- Strong principles-oriented perspective
- Useful historical and practical context

## Cons

- Not a step-by-step implementation guide
- Opinionated writing style

## Best for

Scrum Masters, Agile Coaches, and developers refining Agile fundamentals.

## Alternatives

- Agile Estimating and Planning
- Essential Scrum
