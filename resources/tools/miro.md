# Miro

## Description

Miro is an online whiteboard platform used for facilitation, planning, workshops, and collaborative Agile ceremonies.

## Why we recommend it

It helps distributed teams run interactive retrospectives, planning sessions, and discovery workshops effectively.

## Pros

- Strong template ecosystem
- Excellent for visual collaboration

## Cons

- Large boards can become cluttered
- Advanced plans can be expensive

## Best for

Remote and hybrid Agile teams running collaborative workshops.

- FigJam
