# Sprint Retrospective Template

## Description

A reusable retrospective format for inspecting team outcomes and defining measurable improvements.

## Why we recommend it

It helps teams run consistent, focused retrospectives with actionable follow-up items.

## Pros

- Encourages structured reflection
- Easy to adapt for remote and in-person teams

## Cons

- Can feel repetitive without facilitation variety
- Needs discipline to track action outcomes

## Best for

Scrum teams that want repeatable, practical retrospective ceremonies.

## Alternatives

- Start Stop Continue template
- 4Ls retrospective format
