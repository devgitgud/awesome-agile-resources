# Definition of Ready Template

## Description

A practical template for establishing the conditions that make a backlog item ready for development.

## Why we recommend it

It helps teams reduce ambiguity, improve quality, and create clearer handoffs between discovery and delivery.

## Pros

- Improves clarity before implementation begins
- Supports healthier sprint planning conversations

## Cons

- Can become overly bureaucratic if overused
- Needs team ownership to stay useful

## Best for

Product Owners, Scrum Masters, and development teams improving execution discipline.

## Alternatives

- Definition of Done checklist
- User story template
